# Portfólio profissional — Rick Assis

Site estático de portfólio para comunicação, design, fotografia e projetos. Feito com HTML, CSS e JavaScript simples, sem frameworks.

## Arquivos
- `index.html`: conteúdo e estrutura do site.
- `style.css`: cores, layout e adaptação para celular.
- `script.js`: menu mobile e ano automático no rodapé.
- `assets/`: coloque aqui suas imagens quando estiver pronto.

## Como personalizar primeiro
1. Abra `index.html`.
2. Procure por `Rick Assis` e ajuste o texto se quiser.
3. Procure por `SEUEMAIL@EXEMPLO.COM` e troque pelo seu e-mail real.
4. Troque o link genérico do LinkedIn pelo seu perfil.
5. Substitua os projetos de exemplo por trabalhos reais seus.
6. Quando tiver uma foto profissional, podemos trocar o cartão ilustrado da primeira tela por sua foto.

## Como publicar
Veja o guia `PASSO_A_PASSO.md`.

## Atenção
Não publique informações confidenciais nem trabalhos que você não tenha autorização para divulgar.
